## 公開までの手順（本人のGOが出たら）
1. GitHubに非公開リポジトリを作成（例：`deadline-countdown-pwa`）。ソース正本はここ。Androidアプリと同じ運用ルール（署名鍵は本人管理、VMは作業コピー）。
2. この4ファイルを push（書き込みは毎回承認カードが出る。内容を確認して承認）。
3. GitHub Pages を有効化（リポジトリ設定で本人が1回操作。連携ツールで代行できるかは未確認のため、実施時に手順を案内する）。
4. 公開URLを iPhone の Safari で開き、動作とオフライン表示を確認してから渡す。
5. 本人が Safari で「ホーム画面に追加」をタップ（1回だけ）。

## 制約（本人へ正直に伝えること）
- プッシュ通知なし。締切が来ても通知は来ず、開いて確認する形。
- データはそのiPhoneの中だけ。機種変更・ブラウザデータ削除で消える。正本が必要な記録には使わない。
- 公開URLは誰でも開ける。登録するのは公開されても困らないイベント名だけ。
- 初期値のうち「日付のみ」の3件と「18時頃」の1件は、時刻が未確認である旨を画面に注記してある。
